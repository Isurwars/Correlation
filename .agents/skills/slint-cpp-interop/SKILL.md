# Slint C++ Integration & Controller Interop Standards

This skill governs modern C++20 bindings with Slint UI components, thread-safe event loop synchronization, dynamic data model wrappers, plot/image rendering, and controller integration.

## 1. Controller Architecture & Initialization Pattern

C++ applications should instantiate generated Slint windows inside dedicated Controller/ViewModel classes (`AppController`, `PlotController`, `FileIOHandler`).

```cpp
#include "AppWindow.h" // Generated by slint_target_sources in CMake
#include <slint/slint.h>
#include <memory>

class AppController {
public:
    explicit AppController(slint::ComponentHandle<AppWindow> window)
        : window_(std::move(window)) {
        bind_callbacks();
    }

private:
    void bind_callbacks() {
        window_->on_run_analysis_requested([this] {
            handle_run_analysis();
        });
    }

    void handle_run_analysis();

    slint::ComponentHandle<AppWindow> window_;
};
```

## 2. Thread-Safe UI Updates (`slint::invoke_from_event_loop`)

### Core Rule
Background threads computing pair distribution functions, reading trajectories, or executing OpenMP loops **must never** mutate Slint properties directly.

### Pattern
Use `slint::invoke_from_event_loop()` to capture weak handles or copies of data and dispatch back to the GUI event loop:

```cpp
void AppController::handle_run_analysis_async() {
    std::thread([this, window = window_] {
        // Heavy computation off main thread
        auto result = run_pdf_calculation();

        // Dispatch back to Slint UI thread
        slint::invoke_from_event_loop([window, res = std::move(result)] {
            window->set_progress_percent(100.0f);
            window->set_status_text(slint::SharedString(res.summary));
        });
    }).detach();
}
```

## 3. Dynamic Model Interop (`slint::VectorModel`)

Use `slint::VectorModel<T>` wrapped in `std::shared_ptr` to populate dynamic lists, combo boxes, or tabular datasets.

```cpp
void populate_preset_list(AppWindow* window, const std::vector<std::string>& presets) {
    auto model = std::make_shared<slint::VectorModel<slint::SharedString>>();
    for (const auto& preset : presets) {
        model->push_back(slint::SharedString(preset));
    }
    window->set_preset_names(model);
}
```

## 4. Plot & Image Buffer Rendering

To render dynamic plots (e.g. Radial Distribution Functions or VACF curves) inside Slint `Image` components:

### A. Rendering SVG Buffers into Slint Image
```cpp
#include <slint/slint.h>

void update_plot_svg(AppWindow* window, const std::string& svg_data) {
    auto image = slint::Image::load_from_svg_data(
        slint::SharedString(svg_data)
    );
    window->set_active_plot_image(image);
}
```

### B. Pixel Buffer Rendering
```cpp
void update_plot_pixels(AppWindow* window, const uint8_t* rgb_data, uint32_t width, uint32_t height) {
    auto pixel_buffer = slint::SharedPixelBuffer<slint::Rgb8Pixel>(width, height);
    std::copy_n(rgb_data, width * height * 3, reinterpret_cast<uint8_t*>(pixel_buffer.begin()));
    window->set_active_plot_image(slint::Image::from_rgb8(pixel_buffer));
}
```

## 5. Unit Testing C++ Controllers (`slint::testing`)

Validate controller state mutations without opening physical display windows using `slint::testing`:

```cpp
#include <gtest/gtest.h>
#include "AppWindow.h"

TEST(AppControllerTest, SynchronizesPresetOptions) {
    auto window = AppWindow::create();
    AppController controller(window);

    // Trigger Slint callback programmatically
    window->global<AppToolTips>().invoke_preset_selected("Amorphous_Si");

    EXPECT_EQ(window->get_active_preset_name(), "Amorphous_Si");
}
```
